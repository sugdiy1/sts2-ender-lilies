# EnderLiliesOriginal

《杀戮尖塔 2》亡灵契约师的外观模组。选角界面显示莉莉丝，战斗中显示莉莉丝与黑衣骑士。

## 安装

1. 在 [Releases](https://github.com/sugdiy1/sts2-ender-lilies/releases) 下载 `EnderLiliesOriginal-0.2.8.zip`。
2. 将解压所得的 `EnderLiliesOriginal` 文件夹放到游戏目录的 `mods` 下。
3. 启动游戏并启用模组，选择亡灵契约师。

在 Windows 游戏 v0.113.1 上验证了 ZIP 单独安装、选角和单人首战，无需 BaseLib 或 RitsuLib。另用两个客户端验证过房主装 EnderLilies、队友不装时能完成联机首战，双方各自看到对应外观。其他游戏版本未验证。

原始美术来自《终焉之莉莉：骑士寂夜》。
